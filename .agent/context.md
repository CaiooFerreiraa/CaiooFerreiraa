# Contexto do Projeto

## Descrição
Perfil do GitHub temático com Pokémon do tipo Fogo. Apresenta o desenvolvedor Caio Ferreira, suas habilidades e seus principais projetos como se fossem um "Time Pokémon".

## Stack / Tecnologias
- GitHub Markdown
- Shields.io (Badges)
- GitHub Readme Stats (Cartões dinâmicos)
- Sprites Animados (PokeAPI / Showdown)

## Convenções e Padrões
- Temática constante de Pokémon do tipo Fogo.
- Layout centralizado no README.
- Uso de tabelas para exibir o "time" de projetos.

## Notas Importantes
- O time deve consistir sempre em 6 Pokémon do tipo Fogo.
- Os projetos em destaque são: Multiverso Literário, Raízes do Sul, Finance Farm, Portfolio Prime, Conecta Saúde e Marketing Place.

---

## Design

### Design System
Pokémon / Retro Gaming Aesthetics

### Paleta de Cores
- Predominantemente tons de vermelho, laranja e amarelo (Fogo).
- Temas escuros nos cartões de status.

### Animações e Transições
Sprites animados no formato GIF para trazer vida ao perfil.
